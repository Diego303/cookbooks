Backend Integration

Esta guía describe cómo integrar tu servicio con nuestra API RESTful. Diseñada para ser intuitiva y predecible, nuestra API utiliza características estándar de HTTP como verbos, códigos de respuesta y autenticación basada en tokens.

Authentication Required

La autenticación se maneja a través del header Authorization. Debes prefijar tu token de API con la palabra clave Bearer.

bash
curl https://api.cookbooks.dev/v1/projects \
  -H "Authorization: Bearer sk_test_51Mz..." \
  -H "Content-Type: application/json"

Rolling Keys

Si sospechas que tu clave ha sido comprometida, puedes rotarla inmediatamente desde el panel de control. Las claves antiguas expirarán tras 24 horas.

Rate Limiting

Limitamos las peticiones para asegurar la estabilidad del sistema. Los límites actuales son de 100 req/min para cuentas gratuitas y 1000 req/min para cuentas Pro.

Si excedes el límite, recibirás un código de estado 429 Too Many Requests.
